---
name: filling-subset-doc
description: Use when you are asked to fill in a subset doc (`./doc/lang/subset*.md`)
---

- First identify the relevant sections of the spec
- For each section, if the implementation doesn't fully match the spec (extra restrictions, or cases the spec doesn't cover), document it under that statement's or expression's bullet
  - If the implementation now supports the full spec, remove all restrictions instead of listing each part as supported
